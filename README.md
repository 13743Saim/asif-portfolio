# Asif Portfolio — Next.js + Motion

A premium animated portfolio starter built with Next.js App Router, React, TypeScript and Motion.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Before publishing

Update these placeholders in `components/Portfolio.tsx`:
- `hello@example.com`
- LinkedIn URL (`href="#"`)
- GitHub URL (`href="#"`)
- Project copy / links / metrics

## Deploy

Push the folder to GitHub and import the repo into Vercel.
